# bench-assets

Pinned files that the BoxRouter benchmarks download into sandboxes: static benchmark tools (7-Zip, STREAM, fio, stress-ng), a small Vite app, and R2E-Gym task tarballs. They are published only as releases of this repository, and every download is checked against a SHA-256 value pinned by the benchmark that uses it. See `NOTICES.md` for the source and licence of each file.
